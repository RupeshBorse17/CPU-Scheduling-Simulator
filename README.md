# 🚀 CPU Scheduling Simulator (C++)

A simple and efficient implementation of core CPU Scheduling algorithms to understand Operating System concepts through practical simulation.

---

## 📌 Overview
This project simulates how processes are scheduled in an operating system using different algorithms. It helps in understanding process execution, waiting time, and turnaround time.

---

## ⚙️ Algorithms Implemented
- 🔹 First Come First Serve (FCFS)
- 🔹 Shortest Job First (SJF)

---

## ✨ Features
- Calculates Waiting Time (WT)
- Calculates Turnaround Time (TAT)
- Computes Average Waiting Time & Turnaround Time
- Simple and clean console-based output
- Easy to understand logic for beginners

---

## 🛠️ Technologies Used
- C++

## 🧠 Concepts Covered
